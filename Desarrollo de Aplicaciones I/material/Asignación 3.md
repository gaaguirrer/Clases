### **Indicaciones Iniciales**

---

Tomando como referente el archivo de ejercicios entregado por su docente, pruebe los 10 programas en python y tome anotaciones de su experiencia estas anotaciones deben enviarse como trabajo de forma individual, a continuación se le proporciona el formato en que las notas deben ser enviadas

### **Formato**

---

|                                                              | Programa 1 | Programa 2 | Programa 3 | Programa ... |
| ------------------------------------------------------------ | ---------- | ---------- | ---------- | ------------ |
| **¿Qué cosas nuevas aprendí?**                      |            |            |            |              |
| **¿Qué cosas nuevas aprendí?**                      |            |            |            |              |
| **¿Cómo puedo implementar lo aprendido?**            |            |            |            |              |
| **¿Qué problemas tuve mientras hacía las pruebas?** |            |            |            |              |
| **¿Qué aprendí al solucionar esos problemas?**      |            |            |            |              |

### **Puntaje**

---

Cada programa en python tendrá un puntaje de 1 punto, para un total de 10 puntos totales en el trabajo. Por lo cual cada pregunta equivale a un 20% de la nota

### **Criterios de Evaluación**

---

+ Las respuestas son frutos de la reflexión de mi propio aprendizaje *60% (1.2 puntos por cada programa)*
+ Expresarse de forma clara y sin ambiguedades *20% (0.4 puntos por cada programa)*
+ Analizar el código detenidamente *20% (0.4 puntos por cada programa)*
