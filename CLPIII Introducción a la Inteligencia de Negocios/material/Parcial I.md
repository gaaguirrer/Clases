## Examen Parcial de Curo Libre Profecional III

### Indicaciones Iniciales

Júntese en trío con un(a) compañero(a) y haciendo uso de la data elaborada en la clase, resuelva las situaciones planteados en la sección de resolución. No es necesario instalar el reporting builder, para el parcial, pero instálelo para la siguiente clase

### Resolución

1. Usando la función de obtener datos, importe la data creada en excel.
2. Una vez que tenga la data en power BI debe crear 4 gráficos a criterio propio
3. Cree un documento en pdf con los gráficos y explique lo siguiente:
   * ¿Qué muestra el gráfico?
   * ¿Por qué eligió mostrar esta información?  / ¿Cuál es la importancia de los datos elegidos para el gráfico?
   * ¿Qué problema se podría solucionar con esta información? / ¿Qué oportunidades se podrían aprovechar con esta información?
   * ¿Por qué eligió este gráfico para mostrar esta información?
4. Envíe la data y el documento pdf con el [sistema de entrega](https://forms.gle/T7YaJGLbaDjWn1ux5) recuerde que es la cuarta entrega

### Criterios de evaluación

* Solución satisfactoria del problema 40%
* Presenta los datos de forma clara y coherente 20 %
* Los graficos usados son los adecuados para lo que se busca presentar 40%
